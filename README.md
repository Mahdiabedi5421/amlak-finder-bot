# ربات فایل‌یاب املاک

نسخه اول: منوی تلگرام برای دو دسته «فروش» و «اجاره» و محدوده‌های موردنظر.

## اجرا

1. Python 3.11 یا جدیدتر نصب کن.
2. وابستگی‌ها را نصب کن:
   pip install -r requirements.txt
3. از BotFather یک Bot Token بگیر.
4. متغیر محیطی BOT_TOKEN را تنظیم کن.
5. اجرا:
   python bot.py

## مرحله بعد

اتصال لایه جمع‌آوری داده‌های مجاز از منابع آگهی، ذخیره در SQLite،
تشخیص فایل‌های جدید/تکراری، نگهداری عکس‌ها و ارسال روزانه به تلگرام.
